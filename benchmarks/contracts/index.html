    About this test

    The benchmark. CUAD, from The Atticus Project: 510 commercial contracts from SEC filings, with the passages for 41 clause types marked by lawyers. CiteOnly was tested on the official 102 test contracts, all 41 questions, with the official scoring code.

    Price. CiteOnly's price is quoted for your volume and documents. Reviewer cost on this page is reviewer hours at the rate on the slider, $50 an hour unless you change it.

    The open model. A public model trained for CUAD and published on 13 September 2026. We ran it on the same 102 contracts with the same code.

    Jev. TypeSafe's model, version of 17 September 2026, run by us on 26 September through its online service, with no tuning and one phrasing of each question. On its own it returns a likelihood per question and no text, so it is shown built into a pipeline: the open model finds and quotes each clause, and Jev keeps the answer when it puts the clause at 50% or more.

    GPT-4.1, Claude Sonnet 4 and Gemini 2.5 Pro. ContractEval's published CUAD results (August 2025), where a quote counts only if it covers the full passage the lawyers marked. They scored .641, .523 and .497; CiteOnly Pro scores .696 and Standard .705 on the same measure. We did not rerun them.

    Time to check. Built from the measured answers of each system on the test set: how many it is sure of, how many quotes, how many changed. The default time to confirm a quote whose place is shown, 22 seconds, is cited from a published study: Slobodkin, Hirsch, Cattan, Schuster and Dagan, Attribute First, then Generate, ACL 2024, where people checked text against the exact passage highlighted. The other inputs are set by the sliders. Reviewing a contract yourself is counted as one read plus finding and writing down each of the 12.2 clauses the lawyers marked in an average test contract.

    The demo contracts. Web site building and hosting agreement (Bolivar Mining Corp., 2003); intellectual property agreement (Hertz Global Holdings, 2016); corporate sponsorship agreement (CurAegis Technologies, 2010). Text and lawyer marks from CUAD; the answers are each system's stored results for that contract.
