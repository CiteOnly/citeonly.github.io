Is this retrieval with citations?

No. Retrieval lets a model write the answer freely. CiteOnly generates the answer as citations, each a passage from your documents and the place it came from.

A retrieval system finds relevant documents and hands them to a language model, which writes the answer in its own words. The writing is where things get invented. A citation added afterwards records which document was nearby, not that it supports the sentence.

The usual remedy is a second model that grades each claim. That model is itself a language model making a judgment. The fabrications it lets through are the ones that look most like the truth.

CiteOnly works the other way round. It generates the citations that answer your question, each with its document and position, and writes nothing freely at any point, so there is no stage to check and no answer without a source.
